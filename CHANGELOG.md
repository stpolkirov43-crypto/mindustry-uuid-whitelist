# Changelog

All notable changes to this project are documented here.

## 1.5 - 2026-10-05

- Added persistent UUID storage in Mindustry settings.
- Added automatic saving after `add`, `remove`, and `clear`.
- Added automatic restoration after restarting the game.
- Added migration support for an in-memory list when the new build is loaded in the same session.
- Added bilingual English and Russian documentation.

## 1.4 - 2026-09-21

- Updated compatibility metadata for Mindustry 160.5.
- Removed the incompatible `Icon.copy` usage.
- Added the `players`, `connections`, and `copy` commands.
- Removed the obsolete `list` command.

## 1.3

- Added F8 command registration and UUID-only filtering.
