# UUID Whitelist

[English version](README.md)

Лёгкий JavaScript-мод для Mindustry, который разрешает подключение только игрокам, чьи UUID находятся в локальном белом списке.

## Возможности

- Проверка подключений только по UUID.
- Управление через консоль F8 во время размещения игры.
- Автоматическое постоянное сохранение списка в настройках Mindustry.
- Окно подключённых игроков с копированием UUID по нажатию.
- История подключений с копированием UUID по нажатию.
- Быстрое копирование UUID последнего подключившегося игрока.
- Отключение встроенного whitelist Mindustry во избежание конфликтующих проверок.

## Совместимость

- Целевая проверенная версия: Mindustry `160.5`.
- Минимальная версия в метаданных мода: `160`.
- Мод предназначен прежде всего для игры, размещённой из настольного клиента, где доступны JavaScript-консоль F8 и графические окна.

## Установка

### Из ZIP-архива

1. Скачайте ZIP из раздела Releases.
2. Откройте раздел **Моды** в Mindustry.
3. Выберите **Импортировать мод** и укажите ZIP.
4. Убедитесь, что в папке модов не осталось старых ZIP или распакованных папок `uuid-whitelist`.
5. Перезапустите Mindustry.

После загрузки в консоли должна появиться строка:

```text
[UUID-WL] LOADED - build 1.5-mindustry-160.5-persistent
```

## Команды F8

Откройте JavaScript-консоль клавишей F8 и используйте:

```javascript
uuidwl("help")
uuidwl("add", "UUID_ИГРОКА")
uuidwl("remove", "UUID_ИГРОКА")
uuidwl("clear")
uuidwl("players")
uuidwl("connections")
uuidwl("copy")
uuidwl("copy", "UUID_ИГРОКА")
```

### Справочник команд

| Команда | Назначение |
| --- | --- |
| `uuidwl("add", "UUID")` | Добавляет UUID и немедленно сохраняет список. |
| `uuidwl("remove", "UUID")` | Удаляет UUID и немедленно сохраняет список. |
| `uuidwl("clear")` | Очищает и сохраняет белый список. |
| `uuidwl("players")` | Открывает список игроков; нажатие по строке копирует UUID. |
| `uuidwl("connections")` | Показывает 50 последних попыток подключения; нажатие копирует UUID. |
| `uuidwl("copy")` | Копирует UUID последнего подключившегося игрока. |
| `uuidwl("copy", "UUID")` | Копирует указанный UUID. |

## Постоянное хранение

Список сохраняется в настройках Mindustry под ключом:

```text
uuid-whitelist.allowed-uuids.v1
```

Изменения после `add`, `remove` и `clear` записываются немедленно и восстанавливаются при следующем запуске игры.

История подключений хранится только до завершения текущей сессии и на диск не записывается.

## Начальные UUID

Начальные записи можно внести в массив `initialUUIDs` внутри `scripts/main.js`. Они применяются только при отсутствии ранее сохранённого списка. Не публикуйте личные UUID игроков в открытом репозитории.

## Предупреждение о безопасности

Этот мод является удобным средством ограничения доступа, но не полноценной системой аутентификации. UUID Mindustry передаётся клиентом и при достаточных знаниях может быть изменён или подменён. Не используйте мод как единственную защиту ценного или общедоступного сервера.

Графические команды `players` и `connections` используют классы интерфейса клиента и без дополнительной адаптации не предназначены для выделенного headless-сервера.
